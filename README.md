# DIY Wallpaper data

Versioned content packages for DIY Wallpaper.

Download the latest catalog manifest from [GitHub Releases](https://github.com/silver-web-data/silver-diy-data/releases/latest/download/content_manifest.json).

Assets use immutable SHA-256 identifiers. Content packages include images, video, fonts, templates, and motion data. The manifest identifies matching packages and their checksums.

Schema version: 1.
